# 🥬 FEIRA: E-commerce de Produtos Agrícolas com Blockchain

A **FEIRA** é uma plataforma digital inovadora que revoluciona a cadeia de suprimentos de alimentos, conectando consumidores diretamente a produtores rurais. Nosso foco é em produtos frescos, de qualidade e na garantia de transações éticas e transparentes através da tecnologia Blockchain.

## ✨ Destaques da Plataforma

| Recurso | Descrição |
| :--- | :--- |
| **Blockchain Integrado** | Garante a **rastreabilidade** e a segurança de cada transação, permitindo ao consumidor saber a origem exata do seu alimento. |
| **Modelo Produtor-Consumidor** | Oferece um fluxo de cadastro e gerenciamento para dois perfis: **Agricultor** (venda direta) e **Cliente** (compra de frescos). |
| **Filtros Inteligentes** | Filtre produtos por tipo, presença de agrotóxicos e, principalmente, por **região do Brasil** através de um mapa interativo. |
| **Sustentabilidade e Economia Justa** | Promove a agricultura consciente, a sustentabilidade e uma economia mais justa, eliminando intermediários. |
| **Experiência de Compra** | Carrinho de compras robusto, checkout completo com cupons de desconto e simulação de frete e pagamento. |

## 🚀 Como Executar o Projeto Localmente

O projeto foi desenvolvido em **React** e utiliza o bundler **Vite**.

**Pré-requisitos:**

* Node.js (versão recomendada: >=18)
* npm (ou yarn)

**Passos:**

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/benedetjv/Feira.git](https://github.com/benedetjv/Feira.git)
    cd Feira
    ```
2.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    ```
3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    # ou
    yarn dev
    ```
    O aplicativo estará rodando em `http://localhost:5173` (ou porta similar).
